# Steganography Tutorial

Implementation of image steganography techniques in ASP.NET Web Forms.

## Features

- Image Encoding
- Message Hiding
- Data Extraction
- Support for Multiple Image Formats

## Components

- Encode Image: Hide messages in images
- Decode Image: Extract hidden messages
- Documentation: Technical implementation details

## Usage

1. Upload source image
2. Enter message to hide (for encoding)
3. Process image
4. Download resulting image
