# WebSockets Tutorial

A demonstration of real-time communication implementations in ASP.NET Web Forms.

## Features

- Native WebSocket Implementation
- SignalR Integration
- Real-time Chat Application
- Custom WebSocket Handler

## Components

- Custom Chat: Basic WebSocket implementation
- SignalR Chat: Enhanced chat using SignalR
- Documentation: Detailed implementation guide
