# AI Integration Tutorial

Demonstrates integration of various AI services in ASP.NET Web Forms.

## Features

- Text Generation with Google's Gemini AI
- Image Generation with Stability AI
- Speech Synthesis with ElevenLabs

## Configuration

API keys need to be configured in Web.config:

- Gemini_ApiKey
- Stability_ApiKey
- ElevenLabs_ApiKey

## Components

- Text Generation: Natural language processing
- Image Generation: AI image creation
- Speech Generation: Text-to-speech conversion
- Documentation: Integration guides

## Usage

1. Configure API keys in Web.config
2. Select desired AI service
3. Input your prompt/parameters
4. Generate content
